## What This Project Is
**BTI Voice** — a shared VOIP/SMS desktop app for the BTI/Talkingvet team. Built with:
- **Frontend:** React (Vite) + Electron (frameless window, ~320px wide like Zoho Voice)
- **Backend:** Node.js/Express + PostgreSQL + Socket.io
- **SMS/Calling:** Twilio (browser-based WebRTC calling via Twilio Client)
- **Deployment:** Railway (`bti-voice` service + Postgres service)
- **Live URL:** `bti-voice-production.up.railway.app`

The app is a narrow, mobile-style single-pane UI. NO "resolve" mechanic — conversations are permanent communication history. All tabs use single-pane navigation (list → detail → back button).

## Key Technical Decisions & Conventions
- **ALL colors** must come from `useColors()` hook — never hardcode colors. Dark palette: bg `#161b24`, panel `#1d2330`, surface `#252d3c`, accent `#4f9cf9`
- **No resolve mechanic** — conversations are permanent. `is_resolved` column stays in DB but frontend never writes to it
- **Fire-and-forget Zoho sync** — Zoho errors must never block user-facing responses. Always wrap in `setImmediate` + try/catch
- **Single-pane navigation** — all tabs use list → detail → back, never split pane
- **Notification bell** — localStorage key `bti_notif_seen_at` tracks read state
- **Agent dropdown** — custom React component, never native `<select>`
- **Default tab** = `'dialpad'`
